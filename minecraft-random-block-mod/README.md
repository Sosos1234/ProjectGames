# Random Block Replace (Fabric)

Мод для Minecraft, который заменяет каждый блок, сломанный игроком, на случайный блок.

## Что делает мод

- Игрок ломает блок.
- На его месте сразу появляется случайный блок.
- Из пула исключаются воздух и жидкие блоки.
- Если случайный блок нельзя поставить в текущую позицию, мод пробует другой.

## Версии

- Minecraft: `1.21.11`
- Fabric Loader: `0.18.2`
- Java: `21`

## Запуск в dev-режиме

```bash
./gradlew runClient
```

## Сборка JAR

```bash
./gradlew build
```

Готовый файл мода будет в:

`build/libs/`
